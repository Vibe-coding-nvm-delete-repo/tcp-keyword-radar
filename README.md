# TCP Keyword Radar

Static dashboard for thecreditpeople.com. Open `index.html`.

Data pulled November 2, 2026:

- 24 converted pages (23 live, 1 gone)
- 11,497 live keyword suggestions and questions
- 22 Google SERPs with 315 People Also Ask questions
- 1,098 Bing SERPs
- 13,105 live pages checked for overlap
- 447 page ideas with a semantic verdict

No build step. The data is in `data/*.js` and loads from `file://` or any static host.

Full method and source notes are in the dashboard's Method tab.
